# Netflix Clone

A responsive Netflix-style landing page built with HTML and CSS as a front-end practice project. It recreates the look of the Netflix India home page and is not affiliated with Netflix.

## Features

- Dark hero section with background image, navigation, and call-to-action
- Membership and entertainment feature sections
- FAQ section and footer links
- Responsive layout using CSS media queries
- Local Netflix logo, background image, and favicon

## Project files

```text
.
├── Assets/
│   ├── images/
│   │   ├── bg.jpg
│   │   └── logo.svg
│   └── videos/
│       └── Video1.m4v
├── favicon.ico
├── index.html
├── README.md
└── style.css
```

Some feature images and videos are loaded from external URLs, and the stylesheet imports a font from Google Fonts. An internet connection is needed to load those resources.

## Run locally

No build tools or package installation are required. Open `index.html` in a web browser, or serve the project directory with a local web server.

## Notes

This is a static front-end demonstration. The sign-in button, language selector, email field, Get Started button, FAQ items, and footer links are visual elements only; they are not connected to a backend or Netflix service.
